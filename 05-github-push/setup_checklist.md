# Before We Start — Setup Checklist

Work through this list before the main exercise. Raise your hand if you need help with any of these.

- [ ] **GitHub account** — go to github.com → Sign up (free)
- [ ] **Git installed** — in your terminal, run `git --version`. It should print a version number, not an error.
- [ ] **Terminal / shell** — Command Prompt or PowerShell (Windows), Terminal (Mac/Linux)
- [ ] **Text editor** — Notepad, VS Code, or any editor you already use

Once all four are ticked, you're ready for the hands-on exercise in `Practical_10_Handout.docx`.
