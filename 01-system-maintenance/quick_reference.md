# Quick Reference — Checking Disk Space & What's Running

## Checking Disk Space

| System | How to check |
|---|---|
| Linux / Mac | Open a terminal and type `df -h`, then press Enter |
| Windows | Open File Explorer → right-click the C: drive → Properties |

Look at the percentage used. **Under 80% is fine. Getting close to 90% or more is a warning sign.**

## Checking What's Running

| System | How to check |
|---|---|
| Linux / Mac | Open a terminal and type `top`, then press Enter (press `q` to quit) |
| Windows | Press Ctrl+Shift+Esc to open Task Manager |

You're just having a look here — you don't need to close or change anything. The goal is to get
comfortable with what "a process" looks like on your system.
