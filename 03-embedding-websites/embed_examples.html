Three Ways to Embed a Product

Open this page in a browser to see all three working. View page source (Ctrl+U) to see the code behind each one. Copy whichever example suits your product into training_page_template.html.

Option 1: Static Image Embed

Simplest option - points at an image file that is updated on a schedule elsewhere (e.g. a climate graphic or forecast map your team already generates).

<img src="https://your-source/forecast-map.png"
     alt="Weekly rainfall forecast map"
     style="max-width:100%;">
<p>Source: [Your NMHS] - updated daily</p>

Option 2: Live Text Widget (rainfall example)

Fetches live data from an API and displays it as text - updates automatically every time the page loads, no manual editing needed.

Loading...
<div id="rain-widget">Loading...</div>
<script>
  fetch("https://api.open-meteo.com/v1/forecast?latitude=-18.1&longitude=178.4&daily=precipitation_sum")
    .then(r => r.json())
    .then(data => {
      document.getElementById("rain-widget").innerText =
        "Today's expected rainfall: " + data.daily.precipitation_sum[0] + " mm";
    });
</script>

Option 3: Live Text Widget (ocean example)

Same idea, different product - a wave height reading.

Loading...
<div id="wave-widget">Loading...</div>
<script>
  // Replace this with your own wave buoy / ERDDAP data source
  document.getElementById("wave-widget").innerText =
    "Current wave height: 1.4 m (sample data)";
